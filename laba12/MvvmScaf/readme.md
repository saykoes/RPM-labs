## Взаимодействие с базами данных в .NET. ADO.NET vs ORM. Обратная инженерия

Изучить основные подходы к взаимодействию с базами данных в приложениях .NET, сравнить низкоуровневый подход ADO.NET с высокоуровневыми ORM-решениями.

### Задание:
Выполнить интеграцию базы данных в существующее приложение «Телефонная книга» (из предыдущих лабораторных работ).
